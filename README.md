# Port Scanner

## Internship Project
This project is developed as part of the CODTECH Cybersecurity & Ethical Hacking Internship.

## Project Description
A simple Python-based Port Scanner that checks common ports on a target IP address or domain and identifies whether they are open or closed.

## Features
- Scans common ports
- Detects open and closed ports
- Uses Python socket library
- Simple command-line interface

- Python
